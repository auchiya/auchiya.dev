I've been using more terminal oriented tools lately.

So I've saved and sync all my config in this repo to have the same development environment across the different computers I have to work on.

I use Chezmoi to manage the dotfiles that keep my Neovim, Lazygit, Ghostty, and Zsh setup in sync across macOS and Windows. I really like that you can have specific OS oriented configs.

Also I've been testing and using the new terminal multiplexer <a href="https://www.superlogical.com/updates/public-testing-beginning">Rex</a> instead of ghostty. Quite good experience so far but, as I'm writting (November 2026) is still in beta, I will not track the config files until the v1 is released and stable.
